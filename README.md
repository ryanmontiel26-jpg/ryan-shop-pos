# ✨ Ryan.ShopMx — Haute Parfumerie POS System

Sistema de punto de venta (POS) y catálogo interactivo de fragancias de alta gama y nicho desarrollado en Python con **Tkinter**.

---

## 🌟 Características

- **Catálogo Exclusivo por Categorías**: Filtrado dinámico entre fragancias Nicho, Diseñador y Decants.
- **Control de Cantidades**: Selector de unidades por producto antes de añadir a la orden.
- **Carrito Inteligente**: Resumen en tiempo real con agrupación de artículos, subtotales y total general.
- **Gestión de Órdenes**: Opciones para vaciar carrito o finalizar venta generando un folio único y fecha.
- **Estética Dark Luxe**: Interfaz oscura con acentos dorados (`#121212` y `#d4af37`), optimizada para pantallas modernas.

---

## 📦 Requisitos e Instalación

1. **Python 3.8 o superior** instalado.
2. `Tkinter` (viene incluido por defecto en las instalaciones oficiales de Python para Windows y macOS).

```bash
# Clonar el repositorio
git clone https://github.com/ryanmontiel26-jpg/ryan-shop-pos.git

# Entrar a la carpeta
cd ryan-shop-pos

# Ejecutar la aplicación
python main.py
```
